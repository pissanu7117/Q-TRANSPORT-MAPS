เพิ่มสถานที่

รองรับการวางลิงก์ Google Maps และพิกัดเอง หากลิงก์สั้นไม่แสดงค่าพิกัด กรุณาตรวจหมุดบนแผนที่ก่อนบันทึก

พิกัดที่เลือกจะถูกใช้ในการนำทาง ชื่อสถานที่ไม่ถูกใช้ค้นหาใน Google Maps

ถ้าอยู่หน้าโรงงาน สามารถบันทึกตำแหน่งปัจจุบันได้ (ต้องอนุญาต GPS และเปิดผ่าน HTTPS)

🏭

ย่อรูปอัตโนมัติและเก็บเฉพาะภาพขนาดเล็กในเครื่อง ไม่อัปโหลดขึ้น GitHub

จัดการโซน

การลบโซนจะไม่ลบสถานที่ แต่จะย้ายสถานที่ในโซนนั้นไปหมวด “อื่น ๆ”

ตั้งค่าและสำรองข้อมูล

💾 ข้อมูลของฉัน

ชื่อสถานที่เก็บใน localStorage ส่วนรูปย่อเก็บใน IndexedDB ของ Safari (ไม่ได้ซิงก์ข้ามเครื่อง) ไฟล์สำรอง JSON เวอร์ชันนี้จะรวมรูปด้วย ควรสำรองเป็นระยะ โดยเฉพาะก่อนล้างข้อมูล Safari หรือเปลี่ยนเครื่อง

🧭 การนำทาง

เปิด Google Maps ด้วยพิกัดที่บันทึกไว้ หากไม่มีพิกัด จะใช้ลิงก์ที่วางไว้ หรือค้นหาชื่อสถานที่

Google Maps ไม่ใช่ระบบเลือกเส้นทางเฉพาะรถบรรทุก โปรดตรวจสอบถนนห้ามรถบรรทุก ความสูง และน้ำหนักก่อนเดินทาง
